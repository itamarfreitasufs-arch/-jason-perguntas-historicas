# Exemplos fictícios

Dezesseis casos construídos para avaliação da versão 0.5.3, antes da correção 0.5.4. Não são fontes históricas reais ou dissertações. Cada pasta contém introdução; nos casos de módulo 2 há também conclusão e referências fictícias. Em módulo 1, não há resultados a fabricar.

Para testar preservando a referência oculta, use apenas uma pasta por conversa e não forneça avaliacao/chave-0.5.3.json ao assistente. Em módulo 2, comece pela conclusão, salve a saída e só depois apresente introdução/referências. Examinar as duas variantes do par antes de responder limita a independência.

Use a chave depois para comparar o núcleo identificado, a modalidade dos achados, as alternativas de reparo e os limites. Os casos são intencionais e alguns são bastante explícitos; bom resultado aqui não prova desempenho geral.
